MortgageLens report generator update

This archive contains the updated source files and project documentation. It intentionally excludes datasets, virtual environments, Git metadata, and Python cache files. Keep your existing data/ folder and .venv.

Apply on Windows:
1. Close the running Streamlit terminal with Ctrl+C.
2. Extract this ZIP directly into your existing MortgageLens project folder, e.g. C:\Users\Savi\Downloads\MortgageLens\MortgageLens.
3. Allow the following files to be replaced when prompted: app.py, requirements.txt, README.md.
4. New files added: src\reporting.py and tests\test_reporting.py.
5. In VS Code, open Terminal > New Terminal and run:
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   python -m pytest -q
   streamlit run app.py

Use the Portfolio Report tab:
- For model metrics in reports, run Model Evaluation > Train and evaluate models first.
- For cross-validation results in the detailed report, run Model Evaluation > Run cross-validation.
- Then open Portfolio Report and download the one-page portfolio summary or detailed technical report in PDF or HTML.
- If you change filters, rerun model/cross-validation analyses to refresh the results.

The report generator uses the current filtered dataset and current analysis results; it does not hard-code the metrics. It states the limits of interpreting HMDA outcome labels and demographic comparisons. Reports are generated in memory and are not written to your project folder automatically.
